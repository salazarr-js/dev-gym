# 💪 Dev Gym

> Collection of coding challenges and practice exercises.

A personal set of JavaScript, TypeScript and Python exercises I’ve enjoyed solving, plus
exercises copied from free practice platforms to train offline.

## 🧠 What’s inside

- Exercises by topic (`general`, `sql`, `react`): `exercises/<topic>/NNN-slug/README.md`
- Solutions per language in `exercises/<topic>/NNN-slug/code/` (`solution.ts`, `solution.py`, `solution.sql`)
- Focused on clarity and learning  

See [exercises/README.md](exercises/README.md) for the index.

## Practice

The goal is to stay sharp: solve each exercise without AI. Looking up docs is fine.
Run the test spec at the end and note the result in the exercise attempt log.

Practice platforms, what each is good for:

| Platform | Cost | Use it for |
|---|---|---|
| [Codility Lessons](https://app.codility.com/programmers/lessons) | Free | Correctness and performance (O(N)) under time, same grader as real Codility tests |
| [HackerRank](https://www.hackerrank.com) | Free | Hidden test cases, project tasks (React, Node, Python), skills certifications |
| [LeetCode](https://leetcode.com) | Free tier, Premium about 35 USD/month | Algorithms and data structures, weekly contests |
| [Exercism](https://exercism.org) | Free | Language fundamentals with mentor feedback (Python, TypeScript) |
| [CodeSignal](https://codesignal.com) | Free practice | General Coding Assessment format: 4 tasks in 70 minutes |
| [Pramp](https://www.pramp.com) | Free | Live mock interviews with a peer |
| [interviewing.io](https://interviewing.io) | Paid per session | Anonymous recorded mock with experienced interviewers; use once before a real process |
